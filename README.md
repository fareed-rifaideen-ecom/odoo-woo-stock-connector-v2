# Odoo 18 WooCommerce Stock Connector (Version 2)
A secure, WordPress-plugin-first integration for exact-SKU inventory synchronization and order management[cite: 2].

## Architecture
* Source of Truth: Odoo 18 inventory[cite: 2].
* Matching logic: Exact unique SKU matching only[cite: 2].
* Operations: Read-only preflight checks, stock synchronization, and Processing-status order imports[cite: 2].

## Security
Never commit API keys or database credentials to this public repository[cite: 1].
