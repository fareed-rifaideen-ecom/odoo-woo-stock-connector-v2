# Odoo 18 WooCommerce Stock Connector (Version 2)
A secure, WordPress-plugin-first integration for exact-SKU inventory synchronization and order management.

* **Plugin URL:** [https://github.com/fareed-rifaideen-ecom/odoo-woo-stock-connector-v2](https://github.com/fareed-rifaideen-ecom/odoo-woo-stock-connector-v2)
* **Author:** Fareed M. Rifaideen
* **Author URL:** [https://fareed-rifaideen.netlify.app/](https://fareed-rifaideen.netlify.app/)

## Architecture
* Source of Truth: Odoo 18 inventory.
* Matching logic: Exact unique SKU matching only.
* Operations: Read-only preflight checks, stock synchronization, and Processing-status order imports.

## Security
Never commit API keys or database credentials to this public repository.
